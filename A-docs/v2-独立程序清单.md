## 二、程序简述

### 1. Excel 工具集 v2（CLI 版）— 咨询部
- 位置：`ConsultDepartment/2/`；入口 `main.py`（2461 行级，含 `__main__`）。
- 功能：Excel 扫描、xls→xlsx 转换、n→1 合并、多条件筛选导出等工具集，命令行形态。
- 附注：另有 `test.py`（测试脚本，不计入程序）。

### 2. Excel 工具集 v3（GUI 版）— 咨询部
- 位置：`ConsultDepartment/3/`；入口 `main.py` + `UI/GUI.py`。
- 功能：v2 的图形化完整版——PyQt5 选表头/筛选对话框，面向施工作业计划/第三方督查计划管控报表。
- 附注：`SuperVisionDepartment/feng/` 与本目录几乎同源（基线存疑项，派生关系待定）。

### 3. Excel 处理工具（feng 版）— 监理部
- 位置：`SuperVisionDepartment/feng/`；入口 `main.py` + `UI/GUI.py`。
- 功能：与咨询部 v3 同源的 Excel 处理 GUI 工具，按负责人（feng）归档的独立交付版本。

### 4. 监理工作计划统计（zeng 版）— 监理部
- 位置：`SuperVisionDepartment/zeng/1/`；入口 `main.py` + `UI/GUI.py`。
- 功能：监理工作计划统计，含 `holiday_update_store` 工作日/节假日计算，PyQt5 GUI。
- 附注：同级 `zeng/2/main.py`（PPT 生成）**无 `__main__` 入口**，为脚本片段，不计入程序。

### 5. 监理履职统计与周报工具 — 安质部
- 位置：`SafetyandQualityDepartment/2/`；入口 `demo.py`（881 行级）。
- 功能：xls→xlsx 转换、抽取监理履职数据、按问题分类统计汇总、生成周报与问题清单。
- 附注：无 requirement/spec，打包来源不可追溯（基线跟踪项 T-2）。

### 6. 日报数据处理 — 科创部
- 位置：`ScienceandTechnologyInnovationDepartment/STID-Daily_morning-hj/`；入口 `main_gui.py`。
- 功能：科创部日报数据处理，早报/晚报指标计算，customtkinter GUI。
- 附注：无 `-hj` 后缀的 `STID-Daily_morning/` 下 `main.py` 为 PyCharm 空占位，不计入程序（基线跟踪项 T-3）。

### 7. CSD-CLI（xls→xlsx 转换）— 咨询部
- 位置：`ConsultDepartment/1/`；入口 `demo.py`（615 行级）。
- 功能：xls→xlsx 批量转换 CLI；有 spec（`CSD-CLI.spec`）但未发现 dist 产物。

### 8. 财务 Excel 工具箱 — 财务部
- 位置：`FinanceDepartment/wang/2/`；入口 `main.py`（2623 行级）+ `UI/GUI.py`（2629 行级 PyQt5）。
- 功能：通用 Excel 工具箱（扫描/转换/合并/多条件筛选导出/表头识别）+ 网络检测、日志等脚手架。
- 附注：requirement.txt 缺 PyQt5/requests/psutil（基线 W-2）。
